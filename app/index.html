Cybernoid editor — first release

Load GAME selects an original 383,230-byte supported game binary. The browser reads it without altering the file on your computer.

Navigation: select a level and room from the logical map, or choose a menu/high-scores, end-level or HUD screen from Other Screens. Special screens are views of existing binary data, not editable gameplay rooms. Topology editing is deliberately disabled.

Tile groups: select Tile Groups for recurring 2×2 patterns recovered from original maps. These stamp as a whole with Pencil when editing is enabled. Protected or out-of-bounds destinations refuse the whole stamp. Compound object groups are view-only until full semantic editing is ported.

Player: Show player at START draws a schematic reference marker on the unique $02B starting tile in a gameplay room, without editing GAME. A retail-accurate ship sprite is not yet identified.

Painting: choose a normal tile from the right palette, tick Enable room tile painting, and use the pencil, line, rectangle or fill. Hold the mouse button to paint; right-click any tile to sample it. Protected special objects cannot be overwritten or inserted.

Save Edits downloads a small JSON describing changed map words, tied to the original GAME by its CRC32. Import Edits applies such a file to the same unmodified source binary, after checking all before-values.

Export GAME checks the supported structural rules and downloads a full-size replacement binary named GAME. Choose where to place the extensionless GAME download when testing. WHDLoad integration will be addressed separately. The export is source-preserving: unchanged words and unmapped binary bytes remain identical.

Limits: this release does not edit graphics, palettes, enemy scripts, topology or complex entities. Validation covers core constraints but is not yet a full port of the legacy Python audit. See the HTML5 Editor Wiki page.

Keyboard: Ctrl+Z Undo, Ctrl+Y or Ctrl+Shift+Z Redo, +/- zoom in 50% steps. All actions also have visible controls.
